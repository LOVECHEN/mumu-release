# mumu-release

MuMu 模拟器 / MuMuPlayer Pro 官方安装包自动镜像 · Automated mirror of official MuMu installers (macOS / Windows · 中国版 + 国际版).

| tag 前缀 | 内容 | 平台 |
|---|---|---|
| `mac-<版本>` | MuMuPlayer Pro 完整 `dmg` + 完整 `tar.gz`(均 Apple Silicon,两种都能装) | macOS |
| `win-<版本>` | 在线安装器 + 中国合体版 + 国内三引擎 + 国际三引擎 `exe` | Windows |

## 下载

到 **[Releases](../../releases)** 按前缀找对应平台,或看 **[Latest](../../releases/latest)**。每个 Release 附 `checksums.sha256` 校验和。

- **macOS**:`MuMuPlayer_<ver>_default.dmg`(中国版)/ `_global.dmg`(国际版)· `MuMuPlayer_<ver>_{default,global}.tar.gz`(新版完整包)/ `MuMuUpdater_<ver>_default.tar.gz`、`MuMuMacUpdater_<ver>-global.tar.gz`(旧名完整包)
- **Windows**:`MuMu_<ver>_gw-win_*.exe` / `MuMu_<ver>_gw-overseas12_*.exe`(在线安装器)· `MuMu-setup-V<ver>-<build>.exe`(中国合体版)· `MuMu-setup-{mumu15,nemux,nxmain}-V<ver>-*.exe` / `MuMu-setup-{mumu15,nemux,nxmain}-V<ver>-overseas-*.exe`(国内/国际分引擎)
