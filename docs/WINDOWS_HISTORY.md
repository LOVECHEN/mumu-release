## 文件名推测

- 早期 ARM 使用 `MuMuPlayerARM_<版本>_gw-update-armbeta.exe`。
- 中期 ARM 同时出现 `MuMuARM_<版本>_gw-update-armbeta.exe` 和 `MuMuARM_<版本>_gw-arm-beta.exe`。
- 中国官网 1.8 系列使用 `MuMuARM_<版本>_gw-arm-beta.exe`；首页渠道偶尔去掉分隔符写成 `gwarmbeta`，两种名称指向相同文件内容。
- 国际官网当前使用 `MuMuARM_<版本>-global_gw-arm-download.exe`；同一文件还会按页面按钮位置出现 `gw-download-arm`、`gw-bottom-arm` 等渠道后缀，版本号与 `-global` 才是产品归档键。
- 官网入口切换存在明显滞后：目前中国首页为 1.8.9、国际首页为 1.8.5，而 CDN 已出现 1.8.10。因此自动化同时读取两站入口，并继续向后探测少量语义版本候选。
- 推测只用于生成 HEAD 候选；HTTP 200、`Content-Length` 和 `Last-Modified` 验证全部通过后才发布。
- `1.8.8` 等按序号看似合理但 CDN 不存在的版本不会创建 Release。
